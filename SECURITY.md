# Security Policy

- This repository contains no secrets. The gateway generates its bearer token at runtime and stores it
  outside the repo (`~/.copilot-lm-gateway/token`); never commit that file or paste it into issues.
- Please report vulnerabilities privately via
  [GitHub Security Advisories](https://github.com/rakshith-ponnappa/vscode-lm-openai-gateway/security/advisories/new)
  rather than opening a public issue.
